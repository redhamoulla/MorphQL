# Selected reference artifacts

This directory contains a compact selection of audited outputs used in the paper:

- `performance_global_v7.csv`: global benchmark summary for the four extraction pipelines;
- `execution_witness_example_v8.json`: a complete projected execution witness.

The complete result archive, including per-query tables, bootstrap comparisons, ablations, and lineage manifests, is maintained in the reproducible supplement associated with the paper.
